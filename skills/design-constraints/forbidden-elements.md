# Forbidden elements

§3.4 explicitly bans the following. ANY occurrence in a generated
game's sprites, levels, or mechanics is a hard reject.

| Forbidden | Why | Examples that violate |
|---|---|---|
| **Number digits** as visual elements | Acquired symbolic knowledge | A sprite shaped like "5"; a HUD that displays the digit 7. |
| **Letters of any alphabet** | Acquired symbolic knowledge | A sprite that spells "GO"; a maze whose walls form the letter A. |
| **Real-world clipart** | Cultural knowledge | A flower sprite, a key sprite, a sword sprite; recognisable iconography. |
| **Cultural conventions** | Acquired association | Green-means-go; red-means-danger; an arrow shape implying direction. |
| **Language** | Acquired knowledge | Any text on the screen, including instructions or labels. |

Note that ABSTRACT shapes resembling letters/objects are OK only if
they are not RECOGNISABLE as the language/object. A vertical bar of
3 cells is fine; a vertical bar with two horizontal cross-strokes
forming a "+" is fine (it's a topological symbol, not a letter); but
a sprite that unambiguously reads as a digit "1" is not.

Tutorial conventions are also forbidden — no on-screen "PRESS UP TO
MOVE" hints. The first level itself is the tutorial; it teaches by
being playable.
