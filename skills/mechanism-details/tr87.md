# tr87 — symbol-cycle-rules

## Summary
Two horizontal rows of symbol sprites — top row `zvojhrjxxm` (premise / left-
hand-side) and bottom row `ztgmtnnufb` (working / right-hand-side). ACTION3/4
move a "scope" cursor (`qvtymdcqear_index`) over slots; ACTION1/2 cycle the
selected slot's symbol forward/backward (sprite-name-suffix increments mod
N). Per-level rules (in `cifzvbcuwqe`) tell the game how the bottom row must
relate to the top row. ACTION1 increments and re-evaluates: when the rule
predicate `bsqsshqpox()` holds, an animation morphs the matching symbol
groups through the colour palette `rhoqllymmn`, then `self.next_level()`.

## Action mapping

| Action | Semantic (game-specific) | Gate / when valid |
|---|---|---|
| ACTION1 | Cycle selected slot's symbol backward (suffix `-1 mod N`) | not in animation |
| ACTION2 | Cycle selected slot's symbol forward | not in animation |
| ACTION3 | Move selection cursor left | not in animation |
| ACTION4 | Move selection cursor right | not in animation |

(`available_actions=[1, 2, 3, 4]` — no clicks.)

## Per-level mechanic progression

| Level | Mechanic introduced (or composed) | Specific challenge / constraint |
|---|---|---|
| 1 | Single rule pair; bottom row should equal a known transform of top row | tutorial: cycle each slot to match |
| 2 | Tree-translation: each bottom symbol must equal another rule's RHS chained | introduces `tree_translation` data |
| 3 | Double translation: bottom symbol's tag-marker chains to another rule | introduces `double_translation` data |
| 4 | Larger row size; per-rule translations | combinatorial planning |
| 5 | `alter_rules` mode: cycling acts on the rules themselves, not the working row | meta-cycling |
| 6 | Composite: all transformation modes + extended budget (256 vs 128) | full stack |

(Per-level random seeds `ofysoutulp = [4, 2, 1, 2, 12, 20]` and
`ripmydnety = [7, 7, 32, 18, 23, 11]` — given a seed, layout/rotations are
deterministic.)

## Win condition
`bsqsshqpox()` walks the top row, matches each prefix against rule LHSs in
`cifzvbcuwqe`, then verifies the corresponding bottom-row prefix matches the
rule's RHS. After `self.yfetxjexviz=0`, plays the colour-morph animation
(palette steps `rhoqllymmn`) for each matched group, then `self.next_level()`.

## Lose condition
`upmkivwyrxz` (steps remaining; level-cap 128 for early levels, 256 for
last) hits 0 → `self.lose()`.

## Notable code patterns
- Symbol cycle by name suffix: `name[:-1] + str((int(name[-1]) + dir) % N + 1)`.
  Reusable as "ordered enum cycling via sprite names".
- Rules as (LHS_list, RHS_list) of sprite groups: `iwbhnvdaao` checks
  prefix-match. Reusable as "context-free grammar over sprite sequences".
- Tree-translation / double-translation as level data flags — each
  introduces a level of indirection over which RHS is the actual target.
- Colour-walk animation through `rhoqllymmn` palette: each tick remaps
  matched groups one palette step. Visual "verifying" animation.
- Per-level seeded random for layout: deterministic but level-different.
