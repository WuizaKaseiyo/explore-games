# ls20 — patrol-collect-sequence

## Summary
The player navigates a 16×16 maze with WASD, collecting "shape pellets"
(`rjlbuycveu`) in a specific sequence prescribed per-level. The player avatar
has three editable attributes — shape, colour, rotation — that can be changed
by stepping on cycling sprites (shape-cycler `ttfwljgohq`, colour-cycler
`soyhouuebz`, rotation-cycler `rhsxkxzdjz`). To "claim" a pellet, the avatar
must reach the pellet cell while shape+colour+rotation match the per-pellet
goal. Patrolling enemies fire bullets that, on contact, push the player back
to the start (3 lives `aqygnziho` per level). Step counter drains 2 per move
(by default).

## Action mapping

| Action | Semantic (game-specific) | Gate / when valid |
|---|---|---|
| ACTION1 | Move avatar one cell up | not in respawn / fade animation |
| ACTION2 | Move avatar one cell down | as above |
| ACTION3 | Move avatar one cell left | as above |
| ACTION4 | Move avatar one cell right | as above |

(`available_actions=[1,2,3,4]` — no clicks.)

## Per-level mechanic progression

| Level | Mechanic introduced (or composed) | Specific challenge / constraint |
|---|---|---|
| 1 | One pellet, no enemies, no fog; avatar only needs to reach it | tutorial; visit the cycle sprites to match the pellet's shape/colour/rot |
| 2 | Two pellets, ordered: must claim in goal order | pellet locks until prior one claimed (`lvrnuajbl`) |
| 3 | First patrolling enemy with bullet stream `xfmluydglp` | dodge bullets; bullet contact pushes back to start |
| 4 | Multi-cycler: multiple shape/colour/rotation tiles scattered | route must include cyclers in the right sequence |
| 5 | Fog-of-war (`Fog` level data set) | reduced visibility around avatar |
| 6 | Pellet sequence with non-trivial colour/rotation requirements per pellet | careful per-pellet param matching |
| 7 | Composite final: enemies + fog + multi-pellet ordered sequence | full stack |

## Win condition
`pbznecvnfr()`: when the avatar steps on a pellet cell with matching
shape/colour/rotation (`bejndxqqzf`), pellet is removed and `lvrnuajbl[i] =
True`. Once every flag is True, returns True → `self.next_level()`.

## Lose condition
- 3 deaths from enemy bullets (`aqygnziho` decremented each respawn; reaches
  0 → `self.lose()`).
- Step counter `_step_counter_ui` reaches 0.

## Internal state
- avatar (`gudziatsk`) and start position `(ltwrkifkx, zyoimjaei)`
- shape index `fwckfzsyc`, colour index `hiaauhahz`, rotation index `cklxociuu`
- per-pellet goal indices: `ldxlnycps` (shape), `yjdexjsoa` (colour),
  `ehwheiwsk` (rotation)
- enemies + bullet sprites in `wsoslqeku` (typed `dboxixicic`); patrol AI in
  `hasivfwip` (typed `twkzhcfelv`)
- lives `aqygnziho` (default 3)
- respawn-fade animation tick `ebfuxzbvn`
- `oeuabekjf` — fog flag
- step decrement per move from `StepsDecrement` data (default 2)

## Notable code patterns
- Three-attribute avatar: shape/colour/rotation are independent indices into
  enumerated lists (`ijessuuig`, `tnkekoeuk`, `dhksvilbb`). Cycle sprites
  bump exactly one. Reusable as "transformer" PC.
- Pellet match predicate `bejndxqqzf` — pure equality on three indices.
- Patrolling-enemy class with cached set of `fjzuynaokm` cells (forbidden
  positions for the AI to step into). Pre-baked path avoidance.
- Hint tile (`hoswmpiqkw`) appears beside a pellet only on level 0 and only
  when the player is one cycle-shift away — interactive tutorial.
- Fog overlay `aqdxgoyvu` covers the entire camera, scaled to 64; toggled on
  death.
